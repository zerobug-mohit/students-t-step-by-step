# Student's t, Step by Step

A slow, friendly walk from the Gamma function to Student's t: why (x̄ − μ)/(S/√n) follows a t distribution with n − 1 degrees of freedom.

Every idea starts in plain words, every derivation runs step by step, and the interactive plots are computed in the browser.

**Read it here:** https://zerobug-mohit.github.io/students-t-step-by-step/
